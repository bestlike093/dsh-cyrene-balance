第一次用？三步就够了
  1. 挑形象：默认立绘已经能用，想换就填路径导入

常用动作

右键保留「换形象」和「一键归位」；显示与隐藏、打开设置走托盘；总在最前在「她的样子」里调。

三步上手

1 · 让她能出现内置立绘已经能用；想换图片、GIF、视频或 Live2D 就去「她的样子」导入。
2 · 让她有声音先选系统语音或本机 TTS，再填 TTS 地址和参考音频。
3 · 定她找你的节奏闲聊频率、提问落在桌宠还是网页卡片，都在「说话与互动」。

形象与气泡

配色只影响气泡、状态栏和设置页，不换立绘素材。

卡片模式不加载立绘，只在审批或提问时弹出小卡片，适合已经有自己形象的用户。切换后桌宠会自动重开。

Live2D 模型有版权，默认发行物不带。只有本机存在 assets/live2d/cyrene/Cyrene.model3.json 时才会生效，缺文件会自动回到立绘。

图片 / GIF / 视频直接选文件；多表情立绘选文件夹并写 sprite.json；Live2D 选含 *.model3.json 的文件夹。导入后会复制到本机数据目录，原文件可以挪走。

浅色壁纸上白边容易糊，可以换深边；也可以按轮廓亮度自动挑。

关掉后桌宠会被其他窗口盖住，需要时从托盘点「显示桌宠」就能叫回来。

气泡显示方式只在这里改；右键菜单保留「换形象」和「一键归位」。

安全须知

API Key 存在哪里

  • 加密后保存在本机，不随插件包分发。
  • 解锁凭据绑在这台机器上，别的电脑拿不到。
  • 配置文件里不留明文。
  • 换机器或重装系统后解不开，需要重新填一次 Key。

会联哪些网

  • 余额只请求 https://api.deepseek.com/user/balance。
  • 提问、审批、任务进程都走 dsh 本机的宿主路由，不出本机。
  • 状态面板读本机 CPU / 内存 / GPU / 电量，只在本机显示。

审批边界

  • 桌宠上只给「允许一次」，没有「总是允许」，也不记规则。
  • 同一时间只挂一个审批，第二个会回落到网页卡片。
  • 任务进程是只读展示，不会替 Agent 改任何东西。

升级前遗留的备份文件可能含明文，确认一切正常后建议删掉。

使用手册

和立绘互动

  • 单击：说句话。
  • 双击：换一个姿势。
  • 长按：播报当前任务进程。
  • 拖动：挪位置，松手后位置和缩放会记住。
  • 切到卡片模式后没有立绘，只在审批或提问时弹出小卡片。

右键菜单

  • 一键归位：把桌宠放回主屏右下角，多屏或改缩放后也能找回来。
  • 其余调整都在这一页；显示与隐藏、打开设置走托盘菜单。

提问和审批在哪弹

  • 由「说话与互动 → 对话与审批」决定：桌宠逐题问、只接单题、两边都问、只走网页卡片。
  • 桌宠收起时来了提问，会自动露出来，但不抢焦点。

余额和额度

  • 默认 30 秒缓存一次，在「概览」点「刷新余额」可以立即拉。
  • 今日消费由余额变化推断，充值不会冲掉已记录的消费。
  • 阈值和今日额度填 0 就是不提醒。

出问题的时候

  • 先点「重启桌宠」，多数情况这样就好了。
  • 还不行：关掉 dsh，删掉 ~/.dsh/storages/cyrene-pet/runtime/，再启动 dsh 会重新部署。
  • 启动链路的日志在 pet-boot.log 和 pet-spawn.log。
没有匹配的设置项 换个词试试，或清空搜索。
