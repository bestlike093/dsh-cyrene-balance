# Cyrene 默认素材清单

本目录是桌面端随包的默认形象素材，来源与使用边界见 [`../ATTRIBUTION.md`](../ATTRIBUTION.md)。

## 来源

- 仓库：`bestlike093/cyrene-balance`
- 版本：commit `c54d9f67b1f41f6f2a383db86d0c4f2ae10d487e`（main）
- 作者：旅人（自绘 / 自制）
- 生成方式：`scripts/prepare-cyrene-assets.ps1` 从本地 `cyrene-balance-*.zip` 解包后压缩
- 原始 zip 不入库；仓库内只保留压缩后的运行时副本

## 目录分工

| 路径 | 内容 | 规格 |
| --- | --- | --- |
| `manifest.json` | 代码读取的路径表（姿态、帧、情绪、头像、音效、贴纸） | — |
| `stand/` | 情绪立绘 | 512px 高，透明 PNG |
| `frames/` | 待机帧 `frame-01..08` | 512px 高 |
| `emoji/` | 表情贴纸 44 张 | 128px 高 |
| `avatar.png` | 状态栏头像 | 128px 高 |
| `audio/` | 问候、任务结束、费用、经验球、语气词音效 | 原码率 |
| `sticker/` | 气泡循环贴纸（GIF） | 原样 |

## 压缩口径

- 立绘 / 帧：最长边压到 512px 高，保持比例与透明通道。
- 表情：最长边压到 128px 高。
- 音效与 GIF：体积已经很小，原样保留。
- 总体积目标 ≤ 8 MB；当前 71 文件 / 3.26 MB。

## 使用边界

- 旅人本人已确认 `cyrene-balance` 是其自有仓库，本目录素材可由本项目自由使用、修改并随包分发。
- 素材本身不单独售卖；向本项目之外的第三方再分发时，仍以旅人的说明为准。
- 用户自行导入的模型与素材仍走 `userData/models`，优先级高于本目录，不会被这里覆盖。
