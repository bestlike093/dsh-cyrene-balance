安全须知

API Key 存在哪里

  • 加密后保存在本机，不随插件包分发。
  • 解锁凭据绑在这台机器上，别的电脑拿不到。
  • 配置文件里不留明文。
  • 换机器或重装系统后解不开，需要重新填一次 Key。

会联哪些网

  • 余额只请求 https://api.deepseek.com/user/balance。
  • 提问、审批、任务进程都走 dsh 本机的宿主路由，不出本机。
  • 状态面板读本机 CPU / 内存 / GPU / 电量，只在本机显示。

审批边界

  • 桌宠上只给「允许一次」，没有「总是允许」，也不记规则。
  • 同一时间只挂一个审批，第二个会回落到网页卡片。
  • 任务进程是只读展示，不会替 Agent 改任何东西。

升级前遗留的备份文件可能含明文，确认一切正常后建议删掉。

使用手册

和立绘互动

  • 单击：说句话。
  • 双击：换一个姿势。
  • 长按：播报当前任务进程。
  • 拖动：挪位置，松手后位置和缩放会记住。
  • 切到卡片模式后没有立绘，只在审批或提问时弹出小卡片。

右键菜单

  • 状态面板：余额、CPU、内存、GPU、电量。
  • 显示方式：气泡轮播余额与台词，或只显示其中一种。
  • 任务进程：当前任务和 todo 列表。
  • 设置：就是这一页。
  • 先藏起来：收进托盘，重启 dsh 后会回来。

提问和审批在哪弹

  • 由「提问 → 对话与审批」决定：桌宠逐题问、只接单题、两边都问、只走网页卡片。
  • 桌宠收起时来了提问，会自动露出来，但不抢焦点。

余额和额度

  • 默认 30 秒缓存一次，右键「刷新余额」可以立即拉。
  • 今日消费由余额变化推断，充值不会冲掉已记录的消费。
  • 阈值和今日额度填 0 就是不提醒。

出问题的时候

  • 先点下面的「重启桌宠」，多数情况这样就好了。
  • 还不行：关掉 dsh，删掉 ~/.dsh/storages/cyrene-pet/runtime/，再启动 dsh 会重新部署。
  • 启动链路的日志在 pet-boot.log 和 pet-spawn.log。
